# Release 0.7.0 checks

Date: 2026-10-23.

## QA report review

The report `/tmp/Ganit-AI-QA-Report-fixes.md` lists four corrected defects.
The branch includes the numeric reply, reply type, disclosure button, and
assumption action repairs. Their regression tests remain in the test suite.

The review reproduced one remaining test failure.
`ModelAnswerTests/automaticOriginCannotReturnAnAnswer` failed when run alone.
Its test clock returned from every sleep immediately. The timeout could
therefore finish before the mock reply. The test now uses the controlled
`FakeSuggestionClock`. It also checks that one request reached the transport.
The test passes when run alone.

The other two observations describe current behavior. A derived line opens
its assumption source card. Copy copies that source. A text answer cannot
replace a calculation or supply a missing numeric input. These rules are
unchanged.

## Release runner repair

Pre-merge CI passed on runner image `20261012.0260.1`. The first main and
release runs used image `20261022.0305.3`. Its default Xcode is 27.1, so the
pinned 27.0 check stopped both jobs. A retry produced the same failure.
No release was published.

CI, nightly fuzz, and release jobs now select
`/Applications/Xcode_27.0.app/Contents/Developer`. Both runner images include
this path. The required version remains 27.0.
