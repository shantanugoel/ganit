# Architecture decision records

Architecture decision records (ADRs) capture choices that constrain Ganit's implementation. Accepted decisions are authoritative until replaced by a new ADR; existing records are not rewritten to hide a later decision.

| ADR | Decision |
| --- | --- |
| [0001](0001-appkit-first.md) | AppKit-first application UI |
| [0002](0002-platform-support.md) | macOS 14+, Apple silicon |
| [0003](0003-numeric-representation.md) | Exact numeric model and BigInt dependency |
| [0004](0004-storage-and-export.md) | Recoverable storage and `.ganit` package format |
| [0005](0005-unit-data.md) | Curated unit data sourced from NIST |
| [0006](0006-currency-provider.md) | Direct ECB currency reference rates |
| [0007](0007-distribution.md) | Notarized direct distribution first |
| [0008](0008-global-shortcut.md) | Explicit user-selected global shortcut |
| [0009](0009-pricing-and-trial.md) | One-time purchase and local trial |
| [0010](0010-locale-policy.md) | Explicit locale with English grammar |
| [0011](0011-update-path.md) | Point to releases before in-app installation |
